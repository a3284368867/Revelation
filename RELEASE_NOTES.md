## 🔧 System Requirements

- **Graphics Card**: OpenGL 4.0+ support required
- **Shader Mod**: Iris Shaders 1.7.0 or newer
- **Minecraft**: 1.16 - Latest

## 📦 Installation

1. Extract `Revelation-x.x.x.zip` to `.minecraft/shaderpacks/`
2. Launch Minecraft with Iris Shaders
3. Select "Revelation" in Shader Packs menu

## ✨ Features

- Physically Based Rendering (PBR)
- High Performance Optimization
- Heuristic Lighting
- Comprehensive mod support
